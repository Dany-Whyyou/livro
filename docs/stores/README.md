## Avant de soumettre

**Bloquant**
- [ ] Politique de confidentialité en ligne, à une adresse publique (les deux stores la demandent)
- [ ] Connexion par SMS opérationnelle (Wirepick) pour Livro Pro et Livro Admin
- [ ] Numéros de test avec code fixe dans Supabase (Authentication → Phone), pour les relecteurs d'Apple et de Google, avec une fiche livreur déjà validée
- [ ] Livro Pro : demande de suppression de compte (bouton dans l'app ou adresse e-mail), exigée par Google et Apple pour les apps avec compte
- [ ] Livro Pro (Google Play) : déclaration du service de premier plan « localisation » + vidéo (voir [livro-pro.md](livro-pro.md#4-google-play--déclaration-du-service-de-premier-plan--localisation-))
- [ ] Captures d'écran (au moins 4 par app et par store)

**À compléter dans les consoles**
- [ ] E-mail d'assistance et site web
- [ ] Questionnaire de classification du contenu (IARC) et étiquette de confidentialité Apple
- [ ] Pays de distribution : Gabon (et éventuellement pays voisins pour la diaspora)
- [ ] Prix : gratuit, sans achats intégrés
